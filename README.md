## 🤝 Services I Can Help With

For small, clearly scoped defensive-security tasks, I can help with:

1. **Splunk log analysis and dashboards** — review authorized log samples, write SPL searches, build dashboards, and document suspicious patterns.
2. **Windows forensic artifact review** — examine supplied Windows registry artifacts related to USB device history and prepare an evidence-based findings report.
3. **SIEM documentation and configuration review** — review lab or non-production Splunk/QRadar configurations, document findings, and provide practical recommendations.

### Typical deliverables

- A written scope and list of evidence reviewed.
- Reproducible searches, configuration notes, or artifact observations.
- Screenshots or tables that support the findings, where appropriate.
- A concise report with conclusions, limitations, and recommended next steps.

**Scope and safety:** I work only on systems, logs, and evidence that the client owns or is explicitly authorized to share. I do not offer unauthorized access, credential theft, malware deployment, or unapproved penetration testing. Production changes, live incident response, and guarantees of threat detection are outside the scope of these portfolio examples.
